基于 HUMAN 3.0 框架的中文互动自我探索静态网站。纯前端、无后端、无外部依赖，可直接部署到 GitHub Pages。

## 3. 发布到 GitHub Pages

1. 新建一个 GitHub 仓库（Public），例如 `human30`。
2. 把本项目**根目录下的所有文件**上传到仓库根目录（`index.html` 必须在根目录，不能多套一层文件夹）。
   ```bash
   git init
   git add .
   git commit -m "Human3.0人生评估 静态原型"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 打开仓库 → **Settings** → 左侧 **Pages**。
4. **Build and deployment** → Source 选择 **Deploy from a branch**；
   Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。
5. 等待 1–2 分钟，页面顶部会出现访问地址，形如：
   `https://<你的用户名>.github.io/<仓库名>/`
6. 打开该地址确认首页正常，再测试完整版入口链接。

> 若仓库名就是 `<你的用户名>.github.io`，访问地址会变成 `https://<你的用户名>.github.io/`，链接格式同理替换域名即可。

**更新内容**：修改文件后 `git push`，Pages 会自动重新构建（约 1 分钟）。浏览器可能缓存旧文件，测试时用无痕窗口或强制刷新。

## 6. 题目与报告规则

- 四个维度：心智、身体、关系与意义、职业与贡献。
- 每个维度有两类题目：
  - **阶段题**（`kind: 'level'`）：选项对应 1.0 / 2.0 / 3.0；
  - **转变题**（`kind: 'phase'`）：选项对应 失调 / 不确定 / 发现。
- 判定方式：阶段题取平均值分档（< 1.75 → 1.0，< 2.5 → 2.0，其余 3.0）；转变题取出现次数最多的一项，平票时按「不确定 → 失调 → 发现」取值。
- 报告**不显示任何数字分数**，也不出现百分比、雷达图或排名。
- 元类型规则（需要四个维度都有回答）：
  1. 最高与最低阶段相差 ≥ 2 → 错位成长型
  2. 平均 ≥ 2.6 → 整合推进型
  3. 平均 ≤ 1.4 → 起步整合型
  4. 四个维度相同 → 均衡探索型
  5. 其余情况取阶段最高的维度 → 思考 / 行动 / 连接 / 建造先行型
- 生活方式原型 = 主导维度 × 该维度的转变阶段（四个维度持平时按整体转变阶段取值）。
- 免费体验版报告始终基于四个维度，不再有“信息不足 / 部分维度”的分支；AI 深聊版报告由模型生成，结构见 PROMPT.md 第十一章。

答题交互：全程逐题模式，一次只显示一道题。**第一次作答后约 320ms 自动进入下一题**；最后一题不自动跳，方便填写笔记；从答题卡跳回去修改答案时不会自动跳走。答题卡按维度列出题号，已答、当前、未答三种状态可区分，点击任意题号可直接跳转（手机端折叠为顶部条，展开是 4 列大按钮，跳题后自动收起）。

报告结构：

- 总览 → 元类型 → 生活方式原型 → 跨维度核心议题（含一个可带走的问题）→ 跨维度建议 → 四个维度卡片。
- 每个维度：发展阶段、转变阶段、优势 2 条、值得关注 2 条、**一条**具体建议（含时间或数量）、可展开的判断依据（第一道阶段题 + 用户当时的选择）。
- 跨维度建议指向最落后的维度，并提醒不要把多个维度同时加码。

可选笔记：最后一道题下方提供可折叠的「补充背景（可选）」，最多 600 字；笔记不参与阶段判断、类型判断或报告计算，只在报告末尾原样展示并标注未参与。

题目、选项与全部文案均为本项目自行编写，仅在概念层面参考 HUMAN 3.0，未复制来源文章或提示词原文。

## 8. 关于数据、AI 与支付

**免费体验版**：

- 回答只保存在页面内存里，刷新或关闭页面即清空；不使用任何存储。
- 没有任何网络请求（除加载自身的 HTML / CSS / JS），没有埋点、统计或第三方脚本。
- 不包含任何 API Key、支付或会员逻辑。

**AI 深聊版**（结构决策见 `docs/adr/0002`、`0003`、`0005`）：

- API Key 由用户自备，只保存在本人浏览器的 localStorage；请求从浏览器直连模型服务商，项目不设服务端、不经手、不留存。
- 对话记录只存本机浏览器：清除浏览器数据或更换设备会永久丢失，不支持跨设备续聊。
- 同意书明示三条：回答直连服务商 / 记录只存本机 / 页面含无 Cookie 计数器。
- 计数器（GoatCounter）只记页面流转、不记回答内容，仅 AI 三屏加载；`config.js` 的 `GOATCOUNTER_URL` 留空即完全关闭。
- 合规扫描（`test/check.js`）对 `assets/ai-chat.js` 以外的所有文件仍然强制执行「无请求、无存储」。

全站不包含任何支付、下单、会员开通逻辑。
